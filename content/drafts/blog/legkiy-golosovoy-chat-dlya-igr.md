## Что сравниваем

Mute для Windows, текущую стабильную версию Discord и TeamSpeak 6. Проверяем одну конфигурацию компьютера с одинаковыми настройками и сценарием звонка. В статье будут точные версии программ, параметры ПК, дата и исходные CSV каждого запуска.

Mute для Windows — нативный клиент на C++ и Win32, без Electron. Это характеристика архитектуры; для сравнения потребления ресурсов нужны измерения.

## Как измеряем

Суммируем Private Working Set всех процессов приложения и его дочерних процессов. Отдельно показываем commit, общий working set, CPU и доступные счётчики GPU. Размер установщика не является расходом оперативной памяти.

Для каждого сценария выполняем три запуска. После стабилизации снимаем показатели каждые две секунды в течение двух минут; публикуем медиану запусков и все исходные данные. Неудачный запуск сохраняем с объяснением. При разбросе более 20% добавляем два запуска по спецификации.

## Сценарии

Открытое главное окно, свёрнутое приложение, голосовой звонок один на один, просмотр трансляции 1080p, отправка такой трансляции и холодный запуск. Настройки по умолчанию, одна гарнитура и одна сеть. Если сценарий недоступен или звонок не установился, пишем об этом вместо подстановки нуля.

## Что эти измерения не доказывают

Тест без запущенной игры не измеряет FPS в игре. Нагрузка при показе экрана не равна нагрузке в простое. Результат на одном Windows-ПК нельзя переносить на macOS, браузер или другую видеокарту.

## Как попробовать Mute

[Выберите приложение для Windows или совместимого Mac](/download). Mac-версия требует Apple Silicon и macOS 14+. Для Intel Mac, Linux и телефона есть [веб-версия](https://beta.mute.ac/welcome). Создайте аккаунт, пригласите друга и проверьте короткий звонок; аккаунт нужен каждому.
