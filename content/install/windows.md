При запуске установщика Windows может показать предупреждение SmartScreen. Так система реагирует на любые новые приложения, которые ещё не набрали «репутацию» у Microsoft, с вирусами это никак не связано. Достаточно один раз разрешить запуск.

## 1. Скачайте установщик

Скачайте файл `mute-win.exe` со страницы [скачивания](/download) и запустите его двойным кликом.

## 2. Если появилось окно «Система Windows защитила ваш компьютер»

Это стандартное предупреждение SmartScreen для новых приложений.

1. Нажмите **«Подробнее»** в тексте предупреждения.
2. Появится кнопка **«Выполнить в любом случае»** — нажмите её.

## 3. Дождитесь установки

Установщик всё сделает сам и запустит Mute после завершения. Ярлык появится в меню «Пуск».

## 4. Готово

Запустите Mute, войдите в аккаунт или зарегистрируйтесь — и можно звонить. Повторять эти шаги при следующих запусках не нужно.
