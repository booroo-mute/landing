Коротко. Если вы оба на ПК с Java Edition, самый простой путь без денег и без своего сервера это мод, который открывает ваш мир другу через интернет: Essential или e4mc. Если хотя бы один из вас на телефоне, у вас Bedrock, и там друг подключается к вашему миру через список друзей Microsoft. Java и Bedrock между собой напрямую не играют. Голосового чата в игре нет ни в одной версии, поэтому созвон собирают рядом. Дальше каждый способ по шагам, с ценами и ограничениями на ноябрь 2026 года.

## Сначала одно: у вас Java или Bedrock

На ПК Minecraft продаётся одним комплектом, в нём обе версии, и в лаунчере они переключаются. Java Edition это версия для Windows, macOS и Linux с модами и своими серверами. Bedrock Edition стоит на телефонах, консолях и в Windows из магазина Microsoft. Играть вместе могут только одинаковые версии: Java с Java, Bedrock с Bedrock. Mojang пишет об этом прямо на странице Realms: владелец Java попадёт только в Realm с игроками Java, владелец Bedrock только к игрокам Bedrock. Исключение одно, и оно для своих серверов: плагин Geyser пускает игроков Bedrock на сервер Java, об этом ниже.

Текущие версии: Java 26.3 вышла 15 сентября 2026 года, 26.4 пока в снапшотах; Bedrock 26.62 от 4 ноября. Нумерация с 2026 года начинается с года, версии 1.22 не существует.

## Как поиграть в Майнкрафт с другом по сети на ПК в Java

Четыре способа, от бесплатного к платному.

**Локальная сеть.** Работает только если вы с другом в одной домашней сети. В версии 26.3 кнопка «Открыть для сети» переехала: в меню игры появился раздел «Сетевая игра» с переключателем доступа по локальной сети и номером порта. Через интернет этот способ не работает: Mojang тестировала подключение к другу напрямую из любой точки в снапшотах 26.2 весной 2026 года, но убрала функцию перед релизом и в 26.3 не вернула. Список друзей, который появился в 26.2 (кнопка на главном экране, клавиша O), показывает, кто онлайн, но зайти в мир друга через него нельзя.

**Мод, который открывает мир через интернет.** Это ответ на вопрос «как поиграть с другом по сети, если мы в разных городах» без сервера и без оплаты.

- Essential. Ставится на Fabric, Forge или NeoForge, поддерживает версии с 1.8 до 26.3. Вы открываете свой одиночный мир, друг заходит через приглашение внутри мода. Хост должен быть онлайн, он и есть сервер; одновременно до 8 игроков; у всех должен стоять одинаковый набор модов. Хостинг бесплатный, платные там только косметика. Работает только с официальной версией игры и аккаунтом Microsoft.
- e4mc. Мод ставит только хост. Он открывает мир по локальной сети, а e4mc выдаёт публичный адрес, который друг вводит в обычном окне «Сетевая игра» без единого мода. Бесплатный и открытый, Fabric, Forge, NeoForge и Quilt, версии с 1.17 по 26.3.

**Свой сервер.** Mojang раздаёт серверную часть Java бесплатно, лицензия прямо разрешает поднимать сервер и звать на него людей. Нужна актуальная Java на компьютере, который будет сервером, и он должен быть включён, пока играют. Если сервер дома, на роутере пробрасывают порт игры, иначе друг снаружи не подключится. Для плагинов ставят Paper, для модов Fabric или Forge. Это самый гибкий способ и самый трудоёмкий, зато именно на него ставятся голосовые моды, о них в конце.

**Realms для Java.** Официальный сервер от Mojang по подписке: 7,99 доллара в месяц, одновременно вы и ещё десять игроков, приглашённым платить не нужно, у новых подписчиков 30 дней пробного периода, с версии 26.3 в Realm зовут кодом приглашения. Модов и плагинов на Realms нет. Подписка оформляется через аккаунт Microsoft, а Microsoft с 2022 года приостановила новые продажи в России, поэтому напрямую российской картой Realms не оплатить.

## Как поиграть по сети в Bedrock: Windows, телефон, консоль

В Bedrock друзей ищут не по адресу, а по аккаунту Microsoft. Добавьте друга в друзья, затем «Играть» → вкладка «Друзья»: там видны миры друзей, в которые можно зайти, если хозяин мира включил сетевую игру в настройках мира. На Windows, Android и iOS хватает бесплатного аккаунта Microsoft; на консолях для игры по сети нужна подписка самой консоли, а в настройках аккаунта должны быть разрешены «Клубы» и «Несколько игроков», это тоже из официальной инструкции Mojang.

Второй путь это серверы из вкладки «Серверы»: крупные проекты вроде The Hive или CubeCraft встроены в игру, свой адрес сервера на Windows и телефонах добавляют вручную. Третий путь это Realms для Bedrock: 3,99 доллара в месяц за вас и двух друзей, 7,99 за Realms Plus на вас и десять игроков с подпиской на Marketplace. Про оплату из России то же, что и для Java.

Кросс-плей внутри Bedrock полный: телефон, Windows из магазина, Xbox, PlayStation и Switch играют в одном мире.

## Как поиграть в Майнкрафт с другом на телефоне

Minecraft на телефоне это всегда Bedrock, поэтому телефон играет с телефоном, с Windows-версией из магазина Microsoft и с консолями через друзей, серверы или Realms, как описано выше. С другом, у которого на ПК Java, напрямую не получится: ему нужен либо тоже Bedrock (на ПК она входит в комплект), либо свой сервер Java с плагином Geyser. Geyser позволяет клиентам Bedrock заходить на сервер Java, а дополнение Floodgate пускает их без аккаунта Java; на Realms такое не поставить.

Разговаривать с телефона удобно там же, где и играть: Mute открывается в браузере телефона, приложение не нужно, подробно на странице [голосовой чат на телефоне](/voice-chat/phone).

## Про лаунчеры: мы описываем только официальный

Все шаги выше относятся к официальному лаунчеру с аккаунтом Microsoft. TLauncher и похожие программы это сторонние лаунчеры, к Mojang и Microsoft они отношения не имеют, и часть способов с ними не работает: Essential, например, прямо пишет, что запускается только с официальной версией игры, потому что проверяет аккаунт Microsoft. Что в таких лаунчерах работает, а что нет, мы не проверяем.

## Голос в Майнкрафте: в игре его нет, созвон рядом

Встроенного голосового чата нет ни в Java, ни в Bedrock, ни на Realms. На своём сервере Java голос добавляют модом: Simple Voice Chat или Plasmo Voice, оба бесплатные, оба требуют мод и на сервере, и у каждого, кто хочет говорить, а Simple Voice Chat ещё и открытый UDP-порт на сервере. На Realms, в Bedrock и на чужом сервере без мода этот путь закрыт. Подробнее про моды в [гайде по голосу в Майнкрафте](/games/minecraft).

Для всех остальных случаев компания держит созвон рядом с игрой. Мы делаем [Mute](/), бесплатный [голосовой чат](/voice-chat) для игр, который работает в России без VPN: звонок один на один или комната до 8 человек, демонстрация экрана со звуком, браузер на телефоне или приложение на ПК. Хозяин мира открывает Essential или сервер, остальные заходят по ссылке в комнату, и голос не зависит ни от версии игры, ни от того, Java у друга или телефон.

## Коротко о частых вопросах

**Как поиграть в Майнкрафт с другом по сети на ПК бесплатно?** В Java поставить Essential или e4mc и открыть свой мир через интернет, либо поднять свой сервер. В Bedrock добавить друга в друзья Microsoft и зайти в его мир через вкладку «Друзья».

**Как поиграть по сети, если мы в разных городах?** Локальная сеть не подойдёт. В Java это мод Essential или e4mc, свой сервер или Realms. В Bedrock друзья Microsoft, серверы или Realms.

**Можно ли играть с телефона с другом на ПК?** Да, если на ПК Bedrock: на Windows она идёт в одном комплекте с Java. С Java на ПК телефон напрямую не соединится, нужен сервер с Geyser.

**Сколько стоит Realms?** Для Java 7,99 доллара в месяц, вы и десять игроков. Для Bedrock 3,99 за вас и двух друзей или 7,99 за Realms Plus на десять игроков. Приглашённым подписка не нужна.

**Есть ли в Майнкрафте голосовой чат?** Нет, ни в одной версии. На своём сервере Java его добавляют модом, во всех остальных случаях созваниваются рядом с игрой.

**Через какой лаунчер играть?** Через официальный, с аккаунтом Microsoft. Сторонние лаунчеры мы не описываем, часть способов, включая Essential, с ними не работает.
