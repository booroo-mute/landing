# Release Notes — Дизайн

## Обзор

Механика для отображения релиз ноутов с поддержкой текста и медиафайлов (картинки, видео).

## Решения

- **Источник данных:** Markdown файлы в репозитории
- **Медиа:** картинки + видео
- **Отображение:** карточки-превью в секции, детальная страница по клику
- **URL:** отдельные страницы `/releases/[slug]`

## Структура файлов

```
/content/releases/
  1-2-0.md
  1-1-0.md
  1-0-0.md

/public/releases/
  1-2-0/
    screenshot.png
    demo.mp4
```

## Формат Markdown файла

```md
---
version: "1.2.0"
date: "2026-01-31"
title: "Обновление 1.2.0"
summary: "Добавлены голосовые сообщения, исправлены ошибки авторизации"
---

## Голосовые сообщения

Теперь можно отправлять голосовые сообщения прямо из чата.

![Скриншот](/releases/1-2-0/screenshot.png)

<video src="/releases/1-2-0/demo.mp4" />

## Исправления

- Исправлены ошибки авторизации
- Улучшена производительность звонков
```

Slug берётся из имени файла: `1-2-0.md` → `/releases/1-2-0`

## Парсинг и данные

**Библиотеки:**
- `gray-matter` — парсинг frontmatter
- `react-markdown` — рендеринг контента

**Поток данных:**

1. **ReleaseNotes секция** — при сборке читает все `.md` файлы, сортирует по дате, передаёт frontmatter в карточки
2. **ReleaseCard** — рендерит превью (date, title, summary), ссылка на `/releases/[slug]`
3. **Страница `/releases/[slug]`** — читает `.md` файл, рендерит полный контент

**Рендеринг медиа:**
- Картинки — стандартный `![alt](url)`
- Видео — кастомный компонент через react-markdown для `<video>` тега

Всё работает на SSG (статическая генерация).

## Страница релиза

**URL:** `/releases/[slug]`

**Структура:**
- Header (общий)
- Контент по центру, max-width ~700px
- Дата + заголовок сверху
- Markdown контент с медиа
- Ссылка назад на главную
- Footer (общий)

**Стилизация:**
- Типографика в стиле сайта
- Картинки — на всю ширину контента
- Видео — с controls, на всю ширину
