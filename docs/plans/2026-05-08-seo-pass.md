No automated test framework runs against the landing today, so verification is HTML-shape inspection plus, for JSON-LD, a parse check.

## Task 2: Add `SoftwareApplication` JSON-LD

**Files:**
- Modify: `app/layout.tsx` (RootLayout body)

**Step 1: Add the JSON-LD `<script>` inside `<body>`**

Add this block near the top of `<body>` (right after the opening tag, before `<OSProvider>`). Keep formatting consistent with the existing Yandex Metrika block already in the file.

```tsx
<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{
    __html: JSON.stringify({
      "@context": "https://schema.org",
      "@type": "SoftwareApplication",
      name: "Mute",
      description:
        "Голосовой чат для игр. Аналог Discord без VPN. Звонки 1:1, комнаты до 8 человек, личные и групповые чаты.",
      url: SITE_URL,
      applicationCategory: "CommunicationApplication",
      operatingSystem: "Windows, macOS",
      inLanguage: "ru",
      offers: {
        "@type": "Offer",
        price: 0,
        priceCurrency: "RUB",
      },
    }),
  }}
/>
```

Do not introduce a separate component — keeping it inline mirrors the Metrika `<Script>` pattern already in this file.

**Step 2: Verify the JSON-LD renders and parses**

Run:
```bash
curl -sS http://localhost:3000/ \
  | python3 -c '
import sys, re, json
html = sys.stdin.read()
m = re.search(r"<script type=\"application/ld\\+json\">(.*?)</script>", html, re.DOTALL)
assert m, "No JSON-LD <script> found"
data = json.loads(m.group(1))
assert data["@type"] == "SoftwareApplication", data
assert data["name"] == "Mute", data
assert data["offers"]["price"] == 0, data
print("OK:", data["@type"], data["name"])
'
```
Expected: `OK: SoftwareApplication Mute`. Any assertion failure means the JSON-LD is missing or malformed.

**Step 3 (optional, recommended): External validator**

Open in browser: https://validator.schema.org/ — paste the page URL `https://mute.ac` (production) or paste the JSON-LD block directly. Expect zero errors. Skip if dev environment has no internet.

