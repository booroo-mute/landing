# Гайд по созданию релизов

## Структура файлов

```
content/releases/
  1-3-0.md              # markdown файл релиза
  1-2-0.md
  ...

public/releases/
  1-3-0/                # папка с медиа для релиза
    screenshot.png
    demo.mp4
  ...
```

## Создание нового релиза

### 1. Создай markdown файл

Файл: `content/releases/<version>.md`

Имя файла = slug в URL. Например:
- `1-3-0.md` → `/releases/1-3-0`
- `2-0-0-beta.md` → `/releases/2-0-0-beta`

### 2. Заполни frontmatter

В начале файла обязательный блок с метаданными:

```md
---
version: "1.3.0"
date: "2026-02-10"
title: "Обновление 1.3.0"
summary: "Краткое описание для карточки на главной (1-2 предложения)"
---
```

| Поле | Описание |
|------|----------|
| `version` | Номер версии |
| `date` | Дата в формате YYYY-MM-DD (для сортировки) |
| `title` | Заголовок релиза |
| `summary` | Краткое описание для превью-карточки |

### 3. Напиши контент

После frontmatter — обычный markdown:

```md
## Заголовок раздела

Текст с описанием функции.

![Описание картинки](/releases/1-3-0/screenshot.png)

## Другой раздел

- Пункт списка
- Ещё пункт
```

## Добавление медиа

### Картинки

1. Создай папку `public/releases/<version>/`
2. Положи туда картинки
3. Ссылайся в markdown:

```md
![Alt текст](/releases/1-3-0/screenshot.png)
```

Форматы: PNG, JPG, SVG, WebP

### Видео

```md
<video src="/releases/1-3-0/demo.mp4" />
```

Видео будет с controls и на всю ширину контента.

## Отображение на сайте

- **Главная страница** — показывает 3 последних релиза (карточки с date, title, summary)
- **Страница релиза** — полный контент с медиа по адресу `/releases/<slug>`
- Релизы сортируются по дате (новые первые)
