# Off-site SEO + LLM-видимость: плейбук

Код на сайте — необходимое, но не достаточное условие. Чтобы Mute появлялся
в выдаче и в ответах нейросетей на «аналог дискорда в россии», нужны
**внешние упоминания**: все топ-10 результатов по этому запросу — чужие
подборки (Habr, Лайфхакер, РБК, hi-tech.mail.ru…), и именно их цитируют
ChatGPT, Алиса и Perplexity. Mute пока не упомянут нигде — это главная
причина невидимости.

Ниже — приоритизированный план действий, выполняется руками (не кодом).

---

## Неделя 0: подключение инструментов (обязательная база)

- [ ] **Яндекс.Вебмастер** (webmaster.yandex.ru): добавить mute.ac → скопировать
      токен метатега в `NEXT_PUBLIC_YANDEX_VERIFICATION` в `.env` → задеплоить →
      подтвердить → отправить sitemap.xml → в «Переобход страниц» отправить
      `/`, `/discord-alternative`, все статьи блога (лимит ~20 URL/день).
- [ ] **Google Search Console**: то же самое, токен в
      `NEXT_PUBLIC_GOOGLE_VERIFICATION`. Отправить sitemap.
- [ ] **Bing Webmaster Tools** (bing.com/webmasters): импортировать сайт из GSC
      одной кнопкой. Критично: индекс Bing питает поиск ChatGPT.
- [ ] **GSC → Removals**: после деплоя noindex на beta.mute.ac запросить
      удаление `beta.mute.ac/*` из выдачи.
- [ ] **Яндекс.Метрика** (счётчик 108242058 уже стоит): настроить цели —
      клик «Скачать», клик «Открыть в браузере», переход в Telegram.
- [ ] После каждого деплоя с новым контентом: `npm run indexnow`.

## Неделя 1: каталоги и базы (бесплатно, самообслуживание)

Каталоги — то, что LLM реально «читают» при обучении и поиске. Приоритет:

1. [ ] **AlternativeTo.net** — создать карточку Mute, указать
       "Discord alternative". Самый цитируемый источник в LLM-ответах вида
       «alternatives to X». Заполнить по-английски, скриншоты обязательно.
2. [ ] **Wikidata** — создать элемент: software, официальный сайт mute.ac,
       ОС Windows/macOS/Web, язык русский. Питает графы знаний и LLM.
       (Википедия — пока НЕ пытаться: без независимых публикаций статью
       удалят за незначимость; вернуться после 2–3 упоминаний в СМИ.)
3. [ ] **startpack.ru** — карточка вендора, категория «Мессенджеры».
4. [ ] **productradar.ru** — запуск (русский Product Hunt); подготовить
       описание + скриншоты + первый комментарий от команды.
5. [ ] **Product Hunt** — глобальный запуск (кормит англоязычные LLM-корпуса).
6. [ ] **otzyvmarketing.ru**, **livebusiness.ru** — карточки продукта.
7. [ ] **SaaSHub**, **Slant** — добавить Mute в вопросы про Discord alternatives.
8. [ ] **Яндекс Бизнес** — зарегистрировать организацию (категория
       «Разработка ПО», сайт mute.ac) — помогает брендовой выдаче.

## Недели 2–6: собственный контент на внешних площадках

9. [ ] **Habr (личный пост, не корпоративный блог)** — техническая история:
       «Как мы вдвоём сделали голосовой чат на WebRTC — без серверов и
       каналов». Честный тон, технические детали (WebRTC, TURN, звук),
       ссылка на mute.ac в конце. Habr сам в топ-10 по целевому запросу
       и плотно представлен в обучающих данных LLM.
10. [ ] **vc.ru** — продуктовая история: «Мы делаем российский аналог
        Discord: что получилось за год». Метрики, фейлы, планы.
11. [ ] **Pikabu** («Лига разработчиков») — мейкерский пост от первого лица.
12. [ ] **Telegram-каналы** — через TGStat отобрать 10–20 каналов
        «Игры»/«Технологии» на 10–100 тыс. подписчиков; писать админам.
        Часть возьмёт бесплатно как «находку», часть — платно (₽3–30 тыс.).

## Постоянно: попадание в существующие подборки (самый быстрый путь в LLM)

Ответы нейросетей собираются из конкретных статей-подборок. Задача —
попасть в них апдейтом. Порядок по достижимости:

13. [ ] **guidesgame.ru** (подборка «8 аналогов Discord») — игровое медиа,
        лояльно к инди; написать редакции.
14. [ ] **lifehacker.ru** (подборка «7 аналогов Discord») — принимают питчи.
15. [ ] **callibri.ru/blog** — «Аналоги Discord для бизнеса».
16. [ ] **hi-tech.mail.ru** — нужен хук («минималистичный аналог без
        серверов»), писать редактору рубрики.
17. [ ] **trends.rbc.ru** — самый сложный; нужен инфоповод (веха по
        пользователям, запуск мобильной версии и т.п.).
18. [ ] НЕ тратить время на: trueconf.ru, voice.vyshka.cloud,
        developers.sber.ru — подборки конкурентов, они не добавят.

**Шаблон питча (3 предложения):**
> Здравствуйте! У вас в статье «Аналоги Discord в России» собраны сервисы
> для замены Discord — мы делаем ещё один: Mute (mute.ac), бесплатный
> минималистичный голосовой чат для геймеров, работает в РФ без VPN
> (звонки 1:1, комнаты до 8 человек, Windows/macOS/браузер). Если будете
> обновлять материал — будем рады попасть в подборку; факты и скриншоты:
> mute.ac/llms-full.txt, лого и материалы пришлём по запросу.

19. [ ] **Отзывы**: попросить активных пользователей из t.me/mutecalls
        оставить честные отзывы на Отзовик / IRecommend / startpack.
        Никогда не покупать и не писать самим — Яндекс это распознаёт,
        и брендовая выдача отравляется надолго.
20. [ ] **4PDA** — завести тему в разделе Windows-софта, отвечать на вопросы.

- [ ] Еженедельно, GSC: Performance с фильтром запросов `discord|дискорд`.

      «аналог дискорда», «аналог дискорда в россии», «замена дискорда»,
      «дискорд без vpn», «российский дискорд», «голосовой чат для игр».
      Вести таблицу.
- [ ] Ежемесячно, LLM-проба — задать трём системам (ChatGPT с поиском,
      Алиса, Perplexity) одинаковые вопросы и записать результат:
      1. «Какие есть аналоги Дискорда в России?»
      2. «Чем заменить Discord для игр без VPN?»
      3. «Что такое mute.ac?»
      Цель: первое упоминание Mute в течение 3–4 месяцев после недель 1–6.

## Правила безопасности (чтобы не получить фильтр)

- Плотность «аналог дискорда» на странице — не более 2–3 упоминаний;
  тексты пишутся для людей (Баден-Баден наказывает за переоптимизацию).
- Одна сравнительная страница (`/discord-alternative`), никаких
  slug-дублей типа /zamena-diskorda (дорвей-фильтр).
- Только правдивые заявления: никакого «E2E-шифрования» и «реестра
  отечественного ПО», пока это не так. LLM сопоставляют источники —
  противоречия убивают доверие.
- Не покупать ссылки на биржах — риск «Минусинска» перевешивает пользу.
